# rivex-scaffold

A project scaffolding plugin for the [Rivex](https://github.com/shregar1/rivex-python) web framework.

## Features

- Scaffolds a new Rivex application with standard layered structure.
- Auto-initializes git repository.
- Auto-installs dependencies into virtual environment.

## Installation

Normally installed as part of rivex extras:

```bash
pip install rivex[scaffold]
```
