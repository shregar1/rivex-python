# rivex-codegen

A resource code generator plugin for the [Rivex](https://github.com/vexarr/rivex) web framework.

## Features

- Parse custom field schemas and endpoint schemas.
- Generate standard layered architecture files (models, DTOs, mappers, services, routers).
- Provides template-driven code generation.

## Installation

Normally installed as part of rivex extras:

```bash
pip install rivex[codegen]
```
